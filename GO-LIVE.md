# Putting the site live (Vercel)

1. Unzip this file. You get one folder: `ritish-portfolio-site`.
2. Go to vercel.com, open your portfolio project.
3. Deployments → drag the `ritish-portfolio-site` folder onto the page (or use "Deploy" → upload folder).
4. Wait for the green "Ready" tick. Your site is live on the same address.

Nothing else is needed: no build step, no settings. The site is plain HTML, CSS, JS and images.
Browsers pick up updates straight away, because the style and script links carry a version stamp.
